# Wedding Invitation Website 💍

A beautiful, elegant, and fully responsive digital wedding invitation website built with **HTML, CSS, and Vanilla JavaScript**. This project is designed to replace traditional paper invitations with a modern, interactive web experience.

---

## 🌐 Live Demo

👉 https://wedding-invitation-three-delta.vercel.app/

---

## ✨ Features

- 💌 Cinematic landing page with hero section
- ⏳ Live countdown timer to the wedding date
- 📖 “Our Story” romantic narrative section
- 🗓️ Interactive event schedule timeline
- 👗 Dress code color guide
- 🏨 Travel & accommodation suggestions
- ❓ FAQ accordion section
- 📍 Google Maps location integration
- 📱 Fully responsive mobile design
- 🎬 Intro envelope/video reveal animation
- 🎵 Background music with auto play after interaction
- 🍔 Mobile navigation menu

---

## 🛠️ Built With

- HTML5
- CSS3 (Custom styling, no frameworks)
- JavaScript (Vanilla JS)
- Google Fonts
- Vercel (Deployment)

## 🚀 How to Run Locally

1. Clone the repository

```bash
git clone https://github.com/Dikachu/wedding-invitation.git
````

2. Open the project folder

```bash
cd wedding-invitation
```

3. Run the project

Simply open `index.html` in your browser:

```bash
start index.html
```

or double-click the file.

---

## 📦 Deployment

This project is deployed using **Vercel**.

To deploy your own version:

1. Push the project to GitHub
2. Go to [https://vercel.com](https://vercel.com)
3. Import the repository
4. Click deploy

---

## 🎨 Customization

You can easily customize:

* Couple names

* Venue details
* Colors (gold, maroon, olive theme)
* Background images & videos
* Music file

All edits are inside `index.html`.
